## 1. 개요 및 사용자 시나리오 (UX)

사용자가 업무나 일과에 몰입해 있을 때, **다음 일과로 전환되기 5초 전부터 시계 전체 레이아웃이 역동적으로 반응하며 카운트다운을 표시**하여 다음 활동을 자연스럽게 준비할 수 있도록 돕습니다.

- **트리거 시점**: 등록된 일과의 시작 시각 `5초 전` (예: 13:00:00 시작 일정인 경우 12:59:55부터 발동)
- **카운트다운 구간**: `5초 -> 4초 -> 3초 -> 2초 -> 1초`
- **전환 완료 (0초)**: 새로운 일과 시작 알림 후 정상 다이얼로 복귀.

---

## 2. 시각적 연출 규격 (Visual Transition Presentation)

```
       ┌──────────────────────────────────────────────────┐
       │     [다이얼 전체 앰버 네온 펄스 글로우 효과]     │
       │                                                  │
       │           ┌──────────────────────────┐           │
       │           │   다음: [점심 식사] 준비  │           │
       │           │            5             │           │  <- (5초 카운트다운 대형 숫자)
       │           │         초 남음...       │           │
       │           └──────────────────────────┘           │
       │                                                  │
       └──────────────────────────────────────────────────┘
```

1. **시계 전체 외곽 테두리 펄스 (Dial Pulse Glow)**:
   - 다이얼 외곽 테두리 링에 경쾌하고 부드러운 골드/앰버 펄스 글로우 (`stroke="#f59e0b"`, `drop-shadow(0 0 16px rgba(245,158,11,0.85))`) 애니메이션 적용.
2. **중앙 영역 카운트다운 오버레이 (Center Countdown Overlay)**:
   - **대형 카운트다운 숫자**: `5`, `4`, `3`, `2`, `1`이 1초마다 박동하며 큼직하게 렌더링 (`text-[48px] font-black text-amber-400`).
   - **상단 배너**: 곧 시작될 일과의 제목 표기 (예: `다음: [오후 협업 및 실행]`).
3. **0초 도달 및 복귀**:
   - 00초가 되는 순간 `시작!` 텍스트가 1초간 깜빡인 후, 즉시 정상 시계 다이얼로 부드럽게 페이드아웃 복귀.
