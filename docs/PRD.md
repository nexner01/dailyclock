# DailyClock 제품 요구사항 정의서 (PRD)

---

## 1. 개요 (Overview)

* **제품명**: DailyClock
* **플랫폼**: 순수 웹 브라우저 (Chromium 기반 - Chrome, Edge 최적화)
* **핵심 컨셉**: 24시간 원형 다이얼 차트와 단일 시침(Single Needle)으로 하루 일과를 직관적으로 파악하고, **Document Picture-in-Picture(PiP)** 기술을 통해 작업 방해 없이 항상 최상단에 띄워두는 미니멀 일정/루틴 트래커.
* **엔지니어링 원칙**: OpenAI Harness Engineering, SDD (Spec-Driven Development), TDD (Test-Driven Development).

---

## 2. 사용자 페르소나 및 핵심 시나리오

1. **시간 시각화가 필요한 지식 근로자/학생**:
   - 모니터 구석에 초경량 시계 위젯을 항상 띄워두고(`Always on Top`), 남은 하루 일과와 현재 시간을 한눈에 확인.
2. **구글 캘린더 & 태스크 중심 사용자**:
   - 기존 구글 캘린더의 회의/일정 및 구글 Tasks의 할 일 항목을 그대로 시계에 불러와 시각화.
   - 단, DailyClock에서 데이터를 조작해 구글 캘린더가 오염되는 것을 방지(안전한 Read-Only).
3. **루틴 기반 생활자**:
   - '평일 루틴', '주말 루틴', '시험 루틴' 등 자체 24시간 일과 템플릿을 등록하고 필요에 따라 빠르게 전환.

---

## 3. 기능 요구사항 명세 (Functional Requirements)

### [FR-01] 24시간 원형 차트 & 단일 시침 (Dial View)
* **24시간 원형 분할**: 0시(자정, 상단/또는 12시 방향)부터 24시간을 360도로 매핑 (1시간 = 15도).
* **일과 블록(Arc) 시각화**: 시작 시간 ~ 종료 시간을 가진 일과를 도넛 차트의 색상 호(Arc)로 렌더링.
* **단일 시침(Single Needle)**: 분침/초침 없이 현재 시각의 위치만 가리키는 지침 1개 표시. 1분 단위 자동 업데이트.
* **자정 래핑(Midnight Crossing)**: 23:00 ~ 02:00과 같이 자정을 넘어가는 일정은 2개의 Arc(23:00~24:00, 00:00~02:00)로 자동 분할 렌더링.

### [FR-02] 항상 최상단 플로팅 뷰 (Document Picture-in-Picture)
* **순수 웹 기반 Always-on-Top**:
  - `window.documentPictureInPicture.requestWindow({ width: 320, height: 320 })` API 활용.
  - 별도 설치 프로그램 없이 브라우저 밖 데스크톱 화면 최상단에 고정되는 독립 윈도우 생성.
* **미니멀 위젯 전용 UI**:
  - 플로팅 창 내부에는 메뉴바, 헤더, 스크롤바 일절 없음.
  - 순수 24시간 원형 차트와 시침만 100% 핏으로 렌더링.
* **창 간 동기화**: 메인 창에서 루틴 변경 시 실시간으로 플로팅 창에 즉각 반영.

### [FR-03] 일정 연동 모드
* 환경설정에서 **구글 캘린더 모드** 또는 **자체 캘린더 모드** 선택 (또는 두 데이터의 레이어 병합 뷰 지원).
* **구글 연동 (Calendar & Tasks)**:
  - Google OAuth 2.0 (Google Identity Services) 연동.
  - 연동 대상: **Google Calendar Events** (시작/종료 시각 있는 일정) + **Google Tasks** (마감 시각 있는 할 일).
  - **엄격한 단방향(Read-Only)**: 구글 계정에서 일정을 읽어오기만 하며, DailyClock에서 구글로 저장/수정하는 API는 제공하지 않음.
* **자체 캘린더 관리 (Local Presets)**:
  - **다중 24시간 일과 템플릿**: 평일, 주말, 마감일 등 복수의 일과표 저장 및 선택 사용.
  - **CRUD 기능**:
    - 신규 등록 (Create): 빈 일과표 생성.
    - 시간표 등록/수정/보기 (Edit/View): 시간 구간(시:분 ~ 시:분), 제목, 색상, 메모 편집.
    - 템플릿 복제 (Duplicate): 기존 템플릿을 기반으로 복사본 생성.
    - 템플릿 삭제 (Delete): 불필요한 템플릿 제거.

### [FR-04] 단축키 및 환경설정 (Settings & Theme)
* **단축키 `F1`**:
  - 메인 창 또는 플로팅 창 어디에서든 `F1` 키를 누르면 브라우저 기본 도움말 창을 막고 환경설정 모달 호출.
  - 플로팅 창에서 `F1` 입력 시 메인 윈도우로 포커스 자동 전환.
* **테마 설정**:
  - 라이트 모드 (Light)
  - 다크 모드 (Dark)
  - 시스템 설정 동기화 (System)
  - 컬러 테마 팔레트 (기본, 모던 파스텔, 네온 나이트, 레트로 등 차트 색상 프리셋 및 사용자 지정).

---

## 4. 비기능 요구사항 (Non-Functional Requirements)

* **성능 및 리소스**: 플로팅 창은 상시 띄워져 있으므로 CPU 점유율 0.5% 미만, 메모리 30MB 이하 유지 (1분 주기 시침 업데이트 외 불필요한 리렌더링 차단).
* **오프라인 우선 (Local-First)**: 자체 캘린더 및 설정은 IndexedDB에 저장되어 인터넷이 끊겨도 완벽 동작.
* **보안 & 프라이버시**: 구글 토큰은 브라우저 세션/로컬 스토리지에만 보관되며 외부 서버로 전송되지 않음 (서버리스 순수 클라이언트 아키텍처).
